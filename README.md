# 📝 Python To-Do App

A simple command-line To-Do application built with Python.

---

## 🚀 Features
- Add new tasks
- Show all tasks
- Edit tasks
- Delete tasks
- Prevent duplicate tasks
- Save tasks to file (persistent storage)

---

## 🛠️ Technologies Used
- Python 3
- File Handling
- CLI (Command Line Interface)

---

## ▶️ How to Run

```bash
python main.py
